## 1. قرارات المنتج
- ساس منصة معرفة سياسية وإعلامية متمحورة حول **الملف ← القضية ← الحدث ← التطور**، مع علاقات متعددة بين المستويات ومصادر موثقة؛ ليست قالب أخبار تقليديًا.
- واجهتان أساسيتان: **قراءة واستكشاف عامة** و**لوحة إدارة تحريرية**. تبقى الروابط المباشرة إلى كل سجل صالحة للمشاركة والفهرسة.
- النشر المبسّط: **إنشاء مسودة ← نشر**؛ المدير والمراجع يمكنهما التعديل والنشر والسحب. «السحب» إخفاء من العرض العام، وليس حذفًا نهائيًا. المراجعة متعددة المراحل القديمة ليست مسار التشغيل الرئيسي.
- الحدث المنشور يمكن أن يستقبل تطورًا جديدًا كمسودة. التطور يحتاج نشرًا مستقلًا. النشر ليس إثباتًا للموثوقية أو التحقق.
- واجهة عربية، أرقام لاتينية `0–9`، تاريخ ميلادي `YYYY/MM/DD`، المنطقة الزمنية `Asia/Aden`.
- الخطان: Thmanyah Sans للواجهة وThmanyah Serif Display للعناوين. الشعار الرسمي يحتوي SAS بالفعل؛ لا تضف كلمة SAS خارجه.

## 4. التشغيل على Windows
الموقع المحلي على كمبيوتر المحل:
```powershell
cd D:\SAS-WEB
git pull --ff-only origin main
npm install
npm run lint
npm run build
npm run dev
```
العنوان: `http://127.0.0.1:3000`؛ الإدارة `/admin`؛ الاستكشاف `/explore`.

ملف `.env.local` المحلي (لا يُرفع إلى GitHub):
```dotenv
NEXT_PUBLIC_SUPABASE_URL=https://nrmwshoytmzcmureetjb.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<PUBLIC_ANON_OR_PUBLISHABLE_KEY>
```
لا تستخدم `service_role` في المتصفح، ولا ترسل مفاتيح خاصة في المحادثة أو الالتزامات.
