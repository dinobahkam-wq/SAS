# تشغيل ساس مباشرة من ChatGPT — المسار المختصر

التاريخ: 14 أكتوبر 2026

## القرار التنفيذي
استخدام اتصالات ChatGPT المصرح بها أصلًا: Supabase لبيانات المنصة وGitHub للشيفرة والتوثيق. لا يتطلب هذا المسار OAuth جديدًا أو إنشاء حساب مدير آلي، ولا يتيح الادعاء بأن مكوّن SAS Operator Private متصل عبر MCP.

## العمليات المتوفرة في قاعدة الإنتاج
- ملفات/قضايا/أحداث: sas_admin_overview, sas_admin_create_draft, sas_admin_update_draft, sas_admin_draft_details, sas_admin_set_links.
- تطورات ومصادر: sas_admin_event_developments, sas_admin_create_development, sas_admin_update_development, sas_admin_add_development_source.
- إحاطات: sas_briefing_admin_list, sas_briefing_admin_save, sas_briefing_admin_set_items.
- وسائط: sas_media_editor_list, sas_media_register, sas_media_link_draft؛ رفع ملفات PNG إلى التخزين ما زال يعتمد على مسار تطبيق موثّق وتفويض مستخدم.
- المراجعة والنشر: sas_event_review_requirements, sas_publication_check, sas_event_workflow, sas_development_review_action, sas_publish_development. يُطلب تأكيد صريح للمادة والنسخة قبل النشر.

## الضوابط العملية
- كل الاستعلامات الخاصة بالإنتاج تستخدم المشروع المعتمد `nrmwshoytmzcmureetjb` وتُفحص النتائج قبل تقرير نجاح العملية.
- استخدم وظائف RPC المقيدة بصلاحيات فريق ساس حيثما كان ذلك ممكنًا. الاتصال الإداري بالأداة قد يتجاوز سياسات RLS، لذا لا تستخدم تعديلًا مباشرًا يتخطى سير التحرير والاعتماد.
- لا تشارك رموز الجلسات أو كلمات المرور في المحادثة ولا تخزنها في GitHub أو ملفات المكوّن.
- لا تدّع أن الوصول إلى Supabase يساوي التحكم بكل المحركات أو أن MCP متصل بـChatGPT مباشرة.
- اسمح للمستخدم بأوامر مباشرة في المحادثة مثل: «اعرض مسودات أحداث الساحل الغربي»، «أنشئ تطورًا جديدًا من المصدر»، «عدّل هذا الخبر»، «أضف مصدرًا»، «افحص جاهزية نشر هذه المادة».

## ما يحتاج استكمالًا
- نشر الإنتاج على Vercel: الاتصال الخاص بهذه المحادثة يواجه 403 للوصول لفريق Vercel؛ يعتمد النشر على CLI المصرح به في جهاز المستخدم لحين إصلاح الاتصال.
- التوليد البصري المباشر وتسجيل ملفات وسائط جديدة يتطلبان اختبار مسار الصور أو اتصال منفصل مصادق عليه.
- التوثيق الكامل لجميع وظائف الموقع واجهات الكتابة العامة والخرائط أو تشغيل الاستوديو ليس مكتملًا.
- ربط SAS Operator Private بخادم MCP يظل مشروعًا لاحقًا، ويمكن إعداده عبر OAuth مدعوم عند الحاجة.
