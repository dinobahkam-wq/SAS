# محرك ساس لصور الأخبار — الحزمة الأولى

**فرع التطوير:** `feature/news-card-studio-v1`  
**المسار المحلي:** `/studio`  
**الحالة:** نسخة أولية للتجربة، غير مدمجة في `main` وغير موصولة بالنشر الخارجي.

## المُنجز
- إدخال عنوان خبر نصي دون إعادة كتابة آلية.
- فئات: خبر، عاجل، بيان رسمي، تنويه، إعلان.
- مقاسات: مربع 1080×1080، عمودي 1080×1350، أفقي 1200×675.
- ألوان: أخضر داكن، حبر داكن، عاجي فاتح.
- شعار ساس الرسمي من مسار محلي وسيط `/api/studio-logo` لمنع مشاكل CORS عند تصدير Canvas.
- خطوط ساس العربية مع تحميل مسبق، وتنسيق التاريخ `YYYY/MM/DD` بتوقيت عدن.
- معاينة فورية ورسم داخل المتصفح وتصدير PNG.
- حساب التفاف الأسطر وإخطار المستخدم إذا كان النص أطول من سعة القالب؛ لا يحدث قصّ صامت متعمد.

## حدود الحزمة
- `/studio` واجهة معاينة وتجربة **غير مقيدة بتسجيل الدخول حاليًا** ولا تمنح صلاحية نشر أو تعديل قاعدة البيانات؛ يجب نقلها إلى لوحة الإدارة وحمايتها قبل النشر العام.
- لا تحفظ تصميمًا في قاعدة البيانات، ولا تستورد تلقائيًا تطورًا من ساس، ولا تنتج منشور فيسبوك مصاحبًا بعد.
- الشعار مستضاف في Supabase؛ تصدير PNG مشروط بنجاح تحميله. يجب فحص الأبعاد والتباين بالعينة قبل اعتماد قالب.
- لا نشر على فيسبوك أو X. تنزيل الصورة يتم على جهاز المستخدم فقط.
- جودة الخط العربي وتوزيع النص وحالات العناوين الطويلة يجب اختبارها في المتصفح؛ لم يُعتمد بصريًا بعد.

## اختبار كمبيوتر المحل
```powershell
cd D:\SAS-WEB
git fetch origin
git switch -c feature/news-card-studio-v1 --track origin/feature/news-card-studio-v1
npm run lint
npm run build
npm run dev
```
ثم افتح `http://127.0.0.1:3000/studio`. لا تدمج الفرع في `main` حتى نجاح اختبارات المقاسات الثلاثة، الشعار والخطوط والعربية والتاريخ وحالات النص الطويل.

للعودة إلى الإصدار المستقر:
```powershell
git switch main
npm run dev
```

## الحزم اللاحقة قبل الدمج
1. اعتماد بصري للقوالب وتحديد الألوان والهوامش والخطوط الرسمية.
2. قفل دخول المحرك للمدير والمراجع وتوحيد التنقل مع `/admin`.
3. استيراد مادة منشورة بشكل صريح، مع الاحتفاظ بمعرّفات المصدر والحدث وسجل القالب.
4. نسخ نص المنصة الاجتماعية ومعاينة النص مع رابط المصدر.
5. مراجعة أمنية وأداء واختبارات تصدير PNG من المتصفحات، ثم دمج مشروط بنتيجة الفحص.


## تحديث V2-A / V2-B — 2026/10/11
- **الحاضنة الفاتحة للشعار:** يُرسم الشعار الأصلي في حاضنة عاجية معتمة في أسفل اليمين لجميع لوحات الألوان.
- **التصميم:** تم تقليل الشريط الجانبي، وضبط الهامش والترويسة والتذييل، وفصل خبر / عاجل / بيان رسمي.
- **البيانات الطويلة:** حقل عنوان مستقل وحقل الجهة المصدرة ومتن البيان كاملًا؛ تقسيم صفحات بقياس الخط الحقيقي في Canvas دون إدراج نقاط حذف صامتة؛ عدد الصفحات وأزرار السابق/التالي وتصدير PNG لجميع الصفحات.
- **الحفاظ على النص:** محرك التقسيم يحافظ على ترتيب الكلمات والفقرات، لكنه يطبّع المسافات البيضاء أثناء توزيع الأسطر. لذلك لا يجوز اعتباره نسخة حرفية للوثيقة الرسمية دون مراجعة المُحرر.
- **التصدير المتعدد:** المتصفح قد يطلب السماح بتنزيل ملفات متعددة؛ ينبغي قبول الأذونات بعد التأكد من عدد الصفحات.
- **قيود مقصودة:** البيان الطويل لا يستخدم القياس الأفقي، وقد يُطلب اختصار *عنوان البيان فقط* إذا تجاوز سطرين؛ متن البيان لا يختصر. لا توجد حتى الآن خاصية تعديل فواصل الصفحات يدويًا، ولا ملف ZIP جامع، ولا اعتماد بصري نهائي.
- **التحقق:** لم ينفّذ البناء داخل بيئة العمل الآلية؛ يلزم `npm run lint` و`npm run build` في كمبيوتر المحل قبل الاعتماد أو الدمج.


## تنفيذ V2-C — 2026/10/11
- وحّد محرك Canvas الخط المُصدَّر على `Sas Thmanyah Serif` بأوزان 400 / 500 / 700، مع بقاء واجهة المحرر بخطها الحالي.
- أضيفت حقول اختيارية لإدخال الملف، القضية، الحدث، ويُرسم مسار التصنيف في أعلى كل صفحة؛ حُدِّد أقصى ارتفاع بصري له بثلاثة أسطر.
- أُضيف شعار جهة مُصدِرة اختياري للبيان الرسمي فقط، يُقرأ محليًا من PNG أو JPEG أو WebP بحد 5MB ويُعرض ضمن بطاقة عاجية مستقلة، مع زر للإزالة. لا يُرفع إلى Supabase.
- تم حساب نقطة بداية متن البيان بناءً على عدد أسطر العنوان، ومسار التصنيف، ووجود شعار الجهة. تستخدم المعاينة والتصدير محرك التخطيط نفسه.
- ظل شعار ساس ثابتًا داخل الحاضنة الفاتحة.
- لا يزال المسار يُدخل يدويًا، ولم يتم ربط اختياراته بالمعرّفات الرسمية في قاعدة المعرفة؛ هذه وظيفة V2-D.
- **اختبار مطلوب:** البناء وعمليات رفع الشعار وإزالته والتحويل بين المقاسات، مع مراجعة البيان الطويل وألا يحدث تصادم أو سقوط في النص. لم يُجر فحص بناء موثّق على جهاز المستخدم لهذه النسخة بعد.
