# Studio V3-C.3 — تحرير الصورة والخبر

التاريخ: 2026/10/11  
الحالة: **منفذ على فرع التطوير، بانتظار اختبار TypeScript والمعاينة على جهاز المستخدم؛ ليس معتمدًا للإنتاج.**

## ما تم تنفيذه

1. مصدر المادة وخيار صيغة الإسناد (المصدر/نقلًا عن/وفقًا لـ) ومكانه قبل الموجز أو بعده، ضمن المتن التحريري. لم يعد يظهر في تذييل الشعار.
2. إضافة اسم اليوم بالعربية قبل التاريخ، مع حساب اليوم من تاريخ ميلادي صالح `YYYY/MM/DD`، وإمكانية إخفائه.
3. تحكمات موضعية مستقلة للعنوان والموجز والصورة والمصدر: الهوامش والإزاحة الأفقية والرأسية، مع حساب ملائم للمساحة وتخفيض حجم العنوان عند الحاجة.
4. **التفاف حقيقي للعنوان حول الصورة الجانبية**: السطور المتقاطعة مع الصورة تستخدم عمودًا أضيق، ثم يواصل النص بعرض أكبر أسفل الصورة. خيار لإيقاف الالتفاف.
5. حقل حقوق/مصدر الصورة وإظهاره داخل الصورة أو تحتها.
6. قص الصورة في أشكال: حاد، مستدير، زوايا مختلطة، دائري، بيضاوي، سداسي، مضلع غير منتظم، حواف متلاشية؛ مع التحكم بحجم الإطار والحدود.
7. الموقع يظهر داخل سياق المحتوى، لا ضمن التذييل.
8. ثلاثة قوالب إعداد سريعة مع حفظ/استعادة/حذف تفضيلات شخصية داخل `localStorage` على الجهاز الحالي. **لا تُحفظ البيانات التحريرية أو ملفات الصور**.
9. تعطيل واجهة الرفع اليدوي للخريطة مؤقتًا؛ حقول الموقع باقية تمهيدًا لاستدعاء خريطة SVG شفافة من ملفات المحافظات عند اكتمال محرك الخرائط.

## نطاق التغييرات

- `app/studio/page.tsx`: حالة المحرر، التخطيط، الرسم، التصدير، القوالب.
- `app/styles.css`: عرض حقول التحكم والمجموعات.
- لم يتغير `main` أو قاعدة بيانات Supabase أو إجراءات النشر.

## حدود معلنة

- الالتفاف هو التفاف **سطور نصية متكيف مع المستطيل الحاوي للصورة**، وليس تشكيل الحروف العربية داخل محيط غير منتظم على مستوى البكسل.
- لا تجري أي جلب آلي لخرائط المحافظات الآن؛ لا تُستخدم خرائط تخمينية.
- حفظ التفضيلات محلي لمتصفح اللابتوب؛ لا مزامنة تلقائية بين الأجهزة.
- الزخارف المتقدمة مثل الكشف التلقائي عن بؤرة الصورة والتحكم المتجهي الحر الكامل غير منفذة.

## اختبارات القبول المطلوبة قبل الدمج

1. `npm run lint` (TypeScript)، و`npm run build` إذا توفرت مساحة كافية.
2. خبر حضرموت الطويل نفسه: صورة يسار/يمين، اختيار التفاف العنوان، وملاحظة استمرار النص أسفل الصورة دون قص.
3. صورة خلفية خافتة: العنوان والموجز واسم المصدر وحقوق الصورة لا تتداخل.
4. 8 أشكال للصورة، وبالأخص الدائرة والسداسي والمختلط والحواف المتلاشية، مع `cover` و`contain`.
5. وضع مصدر المادة قبل الموجز وبعده، وإدخال مصدر صورة منفصل.
6. التاريخ `2026/10/11` يجب أن يسبق بيوم `الأحد`؛ إلغاء خيار اليوم يُظهر التاريخ وحده.
7. حفظ قالب شخصي، تحديث الصفحة، استرجاع الإعدادات، ثم حذفه.
8. مقاسات `1080×1350`, `1080×1080`, `1200×675` وخيارات العرض/الارتفاع المخصص.
9. التحقق من أن البيان الرسمي والاقتباس ما زالا يعملان وأن المصدر يظهر داخل المساحة التحريرية.
10. مراجعة المصدر القانوني للصور والخرائط قبل النشر الفعلي.
